# הסוכן האישי שלי — Life Agent

אפליקציית ווב עצמאית: מתעד פעילויות (כוח, אומנויות לחימה, סלסה, גיטרה, צילום), מסווגת אותן אוטומטית, ומריצה **agent אמיתי עם tool use** — אפשר לשאול אותו שאלות בטקסט או בקול, והוא מחליט בעצמו אם לחפש ביומן שלך או לבדוק מזג אוויר לפני שהוא עונה.

משתמש במודל **Gemini 2.5 Flash** של Google — יש לו שכבת שימוש חינמית אמיתית דרך Google AI Studio, בלי כרטיס אשראי.

## שלב 1: מפתח API חינמי (Google AI Studio)
1. היכנס ל-**aistudio.google.com**, התחבר עם חשבון Google.
2. לחץ **"Get API key"** → **"Create API key"**.
3. העתק את המפתח (מתחיל ב-`AIza...`).

⚠️ הערה חשובה: בשכבה החינמית, גוגל עשויה להשתמש בתוכן ששלחת לשיפור המודלים שלה. אל תזין ביומן מידע רגיש אמיתי — זה פרויקט פורטפוליו, לא כלי לניהול מידע פרטי אמיתי.

## הרצה מקומית
```bash
npm install
cp .env.example .env   # הדבק את המפתח האמיתי במקום AIza...
npm start
```
פתח http://localhost:3000

## פריסה לאינטרנט (Render, חינמי)
1. העלה את התיקייה הזו ל-repo חדש ב-GitHub.
2. היכנס ל-render.com → New → Web Service → חבר את ה-repo.
3. Build command: `npm install` | Start command: `npm start`.
4. תחת Environment, הוסף משתנה `GEMINI_API_KEY` עם המפתח מלמעלה.
5. Deploy — Render ייתן לך קישור ציבורי (`https://your-app.onrender.com`).

## מה חדש: ה-Agent
בקובץ `server.js`, הפונקציה `runAgent` מממשת לולאת tool-use אמיתית: המודל מקבל שני "כלים" (`search_journal`, `get_weather`), ומחליט בעצמו אם ומתי להפעיל אותם, לפני שהוא מנסח תשובה סופית.

**הערה על `search_journal`**: זה חיפוש לפי מילות מפתח (RAG פשוט: retrieve + generate), לא חיפוש סמנטי-וקטורי אמיתי. חיפוש סמנטי דורש מודל embeddings + מסד נתונים וקטורי — שדרוג טבעי להמשך.

**קלט קולי**: מבוסס על Web Speech API של הדפדפן (Chrome/Edge) — התמלול קורה מקומית, לא נשלח לשרת עד שהטקסט מוכן.

## אבטחה — מה מוגן ומה לא
- מפתח ה-API יושב רק על השרת (משתנה סביבה), אף פעם לא נשלח לדפדפן.
- HTTPS אוטומטי דרך Render.
- Rate limiting: 15 קריאות ל-AI כל 10 דקות לכל IP, הודעה מוגבלת ל-500 תווים.
- אין אימות אמיתי — הפרדת משתמשים מבוססת UUID אנונימי שנוצר בדפדפן.
- הנתונים לא מוצפנים בדיסק (קובץ JSON רגיל) — מספיק לדמו ציבורי, לא לייצור עם מידע רגיש.
- שכבת השימוש החינמית של Gemini עשויה לשמור תוכן לשיפור מודלים — ראה הערה למעלה.

## מה להראות בראיון
- Tool use / function calling אמיתי — מודל שמחליט בעצמו להפעיל כלים (RAG + agent pattern).
- קריאה ל-LLM API משרת (לא מהדפדפן) — ניהול נכון של מפתח API.
- ארכיטקטורה ניתנת להחלפת ספק LLM (Gemini/Anthropic/OpenAI) בשינוי מינימלי.
- הבנה מודעת של הפער בין חיפוש מילות-מפתח לחיפוש סמנטי אמיתי.
- הפרדת משתמשים אנונימית, rate limiting, מודעות לעלויות ולפרטיות.
